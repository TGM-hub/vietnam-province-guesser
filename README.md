# Tỉnh Việt Nam : provinces du Vietnam

🔗 https://tgm-hub.github.io/vietnam-province-guesser/

Trainer GeoGuessr : placer les 63 provinces du Vietnam (découpage d'avant la fusion de 2025, celui de la couverture Street View actuelle).

## Modes
- **Niveau** : région seulement (8 grandes régions), région puis province, ou province directement.
- **Régions travaillées** : limiter la série à certaines régions (aucune sélection = tout le pays).
- **Carte d'étude** (« Les 63 provinces ») : navigation libre, recherche par nom ou par initiales (« hcm », « brvt », « tth » → Huế), mention « Depuis 2025 : fusionnée dans X ».
- **Où tu te trompes** : historique des erreurs et réussite par province.

## Liens directs
- `#vn`, `#study` ou `#carte` : ouvre la carte d'étude.
- `#<clé>` (ex. `#ha_noi`) : zoome sur la province.
- `?daily=600` : bloc de révision chronométré (lancé depuis la révision de l'Atlas).

## Données
- Progression dans le navigateur (`tinhvn.v1`), export JSON dans Réglages.
- Lien retour vers l'[Atlas](https://tgm-hub.github.io/Atlas/) et la révision du jour.
